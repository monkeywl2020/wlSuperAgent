提示词结构：
--------------------------------------------------------------------------------
messages = [
    # 历史记录（按时序排列）
    {"role": "user",      "content": "上一轮问题"},
    {"role": "assistant", "content": "上一轮回答"},
    {"role": "user",      "content": "再上一轮..."},
    {"role": "assistant", "content": "..."},
    
    # 当前输入（最后一条）
    {"role": "user",      "content": "当前用户输入"}
]

# system 单独传
system = "你是一个专业的客服助手，..."

--------------------------------------------------------------------------------
要求：
系统提示词与其他独立。 只有"全局指令"才属于 System，其余按性质归位
System Prompt（只放稳定内容）

历史对话记录（分离式）

{"role": "user",      "content": "当前用户输入"}
知识库动态内容一般会放到 user 消息里面去以结构化的方式存放。
--------------------------------------------------------------------------------
历史对话记录最好是放到单独的消息中而不是system提示词中，原因是：
主流大模型（GPT、Claude、Gemini 等）在训练时使用的就是 system / user / assistant 的多轮结构。模型对角色归属有天然的理解，把历史塞进 system 会破坏这种语义对齐。
分块结构让模型能自然地对"近期对话"给予更高权重，而融合进 system 会使历史记录获得不该有的持续高权重

--------------------------------------------------------------------------------
一般 提示词框架如下：

┌─────────────────────────────────────────────┐
│  SYSTEM PROMPT                              │
│  · 角色定义                                 │
│  · 能力边界 & 行为规则                      │
│  · 输出格式要求                             │
│  · 工具使用说明（如有）                     │
│  · 少量固定背景知识（可选）                 │
└─────────────────────────────────────────────┘
          ↓
┌─────────────────────────────────────────────┐
│  MESSAGES（历史轮次）                       │
│  user:      ...                             │
│  assistant: ...                             │
│  user:      ...                             │
│  assistant: ...                             │
└─────────────────────────────────────────────┘
          ↓
┌─────────────────────────────────────────────┐
│  CURRENT USER MESSAGE                       │
│  <context>                                  │
│    [动态检索的知识库内容]                   │
│  </context>                                 │
│                                             │
│  用户输入: {query}                          │
└─────────────────────────────────────────────┘
