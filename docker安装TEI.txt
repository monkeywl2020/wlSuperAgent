


===========================安装nvidia-container-toolkit ===========================================================
-------步骤 0：下载gpgkey，然后通过这个来更新apt仓库，然后下载nvidia-container-toolkit.list ,最后 apt命令安装。
------------1： 先从  https://nvidia.github.io/libnvidia-container/gpgkey 下载了 gpgkey.
这个下载下来后上传到服务器。

------------2： 在服务器上转换格式
# 假设文件在当前目录，名为 gpgkey
sudo gpg --dearmor -o /usr/share/keyrings/nvidia-container-toolkit-keyring.gpg ./gpgkey

------------3：# 查看 keyring 中的密钥信息 查看是否成功。
gpg --keyring /usr/share/keyrings/nvidia-container-toolkit-keyring.gpg --list-keys

# 成功输出示例：
pub   rsa4096 2022-03-xx/xxxxxx
uid                      NVIDIA Corporation (Official Key)
=========================================================================================

-------步骤 1：重新配置仓库（替换为 USTC 镜像）
----------------# 1. 备份旧的源配置（如果存在）
sudo mv /etc/apt/sources.list.d/nvidia-container-toolkit.list \
        /etc/apt/sources.list.d/nvidia-container-toolkit.list.bak 2>/dev/null || true

----------------# 2. 使用中科大镜像源添加仓库（自动处理 noble→jammy 兼容）
curl -fsSL https://mirrors.ustc.edu.cn/libnvidia-container/stable/deb/nvidia-container-toolkit.list | \
  sed 's#deb https://nvidia.github.io#deb [signed-by=/usr/share/keyrings/nvidia-container-toolkit-keyring.gpg] https://mirrors.ustc.edu.cn#g' | \
  sudo tee /etc/apt/sources.list.d/nvidia-container-toolkit.list

----------------# 3. 关键：将 noble 替换为 jammy（Ubuntu 24.04 兼容）
sudo sed -i 's/noble/jammy/g' /etc/apt/sources.list.d/nvidia-container-toolkit.list
=========================================================================================

-------步骤 2：更新并安装
sudo apt-get update
sudo apt-get install -y nvidia-container-toolkit
=========================================================================================

------ Docker 未配置 nvidia 运行时：
sudo nvidia-ctk runtime configure --runtime=docker && sudo systemctl restart docker

=====================下载 TEI 镜像，从南京大学镜像站下载====================================================================
------ 1：下载镜像  通用加速器 ghcr.1ms.run 南京的会卡住
docker pull ghcr.1ms.run/huggingface/text-embeddings-inference:cuda-1.9

------ 2. 重新打标签为官方名称（关键！否则 TEI 命令会找不到镜像）
docker tag ghcr.1ms.run/huggingface/text-embeddings-inference:cuda-1.9 \
         ghcr.io/huggingface/text-embeddings-inference:cuda-1.9

------ 3. 验证镜像存在
docker images | grep text-embeddings-inference
# 应看到: ghcr.io/huggingface/text-embeddings-inference   cuda-1.9

==================== 运行 Embedding -- 本地/models/Qwen3-Embedding-0.6B  

#-----------指定 TEI的服务端口为 60010
docker run --gpus '"device=0"' -p 60010:60010 -v /models/Qwen3-Embedding-0.6B:/models/Qwen3-Embedding-0.6B --pull never ghcr.io/huggingface/text-embeddings-inference:cuda-1.9 --model-id /models/Qwen3-Embedding-0.6B --port 60010
