------------## sandbox 沙箱
wlsuperagent 的沙箱采用的是docker 容器安装了ubuntu系统（基于 python:3.12-slim 基于 Debian 系统，ubuntu是debian的分支）

默认 sandbox是随着 wlsuperagent启动而初始化加载docker容器的。但是 python:3.12-slim 默认使用的是默认镜像源，需要修改镜像源，后续才能安装软件包。
同时，curl和ping命令也没有安装。这个需要修改镜像源。安装必要的软件包。

在sandbox的docker环境下跟换为阿里云的源，并安装了上面软件的时候只是当次生效。系统重启后，下次就会失效。
所以比较方便的做法是直接将当前这些个内置的安装包直接编译成 docker镜像。这样加载这个镜像就可以了。后续这些工具都默认都有。
所以需要 docker创建自定义镜像。然后将这个自定义镜像作为sandbox的加载的容器镜像即可。

代码中只需要在配置中修改docker镜像的名称就可以了。

########################################################################
------------ Dockerfile 用来构建镜像的Dockerfile文件

# ==========================================
# 自定义 Sandbox 镜像
# 基于 python:3.12-slim，配置阿里云源并预装工具
# ==========================================

FROM python:3.12-slim

# 避免交互式提示
ENV DEBIAN_FRONTEND=noninteractive

# ========== 1. 配置阿里云apt源 ==========
COPY sources/debian-aliyun.sources /etc/apt/sources.list.d/debian.sources

# ========== 2. 更新并安装工具 ==========
RUN apt-get update \
    && apt-get install -y --no-install-recommends \
        curl \
        iputils-ping \
        wget \
        unzip \
        zip \
    && apt-get clean \
    && rm -rf /var/lib/apt/lists/*

# ========== 3. 验证 ==========
RUN echo "=== 工具验证 ===" \
    && command -v curl && echo "curl: OK" \
    && command -v ping && echo "ping: OK" \
    && command -v wget && echo "wget: OK"

WORKDIR /workspace

----------------- 1：构建自定义 docker镜像 
   
Docker 构建要素详解：
┌─────────────────────────────────────────────────────────────┐
│                    docker build 命令                        │
├─────────────────────────────────────────────────────────────┤
│  docker build          # 构建镜像                           │
│       --no-cache       # 不使用缓存，强制重新构建           │
│       -t wlagent-sandbox:1.0  # 镜像名:标签                 │
│       .                # 构建上下文 = 当前目录              │
└─────────────────────────────────────────────────────────────┘
**构建过程：**
Dockerfile  +  当前目录文件（sources/）  →  Docker daemon  →  镜像

**Dockerfile 每行解析：**

| 指令 | 作用 | 注意事项 |
|------|------|----------|
| `FROM python:3.12-slim` | 基础镜像（一切从这里开始） | 必须是第一条指令 |
| `ENV DEBIAN_FRONTEND=noninteractive` | 设置环境变量（避免 apt 交互提示） | |
| `COPY sources/debian-aliyun.sources ...` | 复制本地文件到镜像 | 源路径相对于**构建上下文**（当前目录） |
| `RUN apt-get update ...` | 执行命令 | 每条 RUN 产生一层，太多层会让镜像臃肿 |
| `WORKDIR /workspace` | 设置工作目录 | 容器启动后的默认位置 |

---

**注意事项：**

| 问题 | 说明 |
|------|------|
| **构建上下文** | `.` 指当前目录，COPY 只能访问这个目录下的文件 |
| **分层缓存** | Docker 会缓存每条指令的结果，加速构建；改内容时只重新构建后面的层 |
| `--no-cache` | 禁用缓存，每次都从头构建（避免缓存导致的旧状态） |
| **文件大小** | 清理 apt 缓存 `apt-get clean && rm -rf /var/lib/apt/lists/*` 可减小镜像体积 |
| **多阶段构建** | 复杂项目可用多个 FROM，分离构建环境和运行环境，镜像更小 |

---

**当前目录结构（构建上下文）：**

```
/workspace/
├── Dockerfile                 # 构建指令
└── sources/
    └── debian-aliyun.sources  # 被 COPY 到镜像的文件
```

COPY 指令找到 `sources/debian-aliyun.sources`，复制到镜像的 `/etc/apt/sources.list.d/debian.sources`。


构建成功后，docker images 可以看到新构建的docker容器。

-------------1.2：docker镜像概念解释。
---  Docker 镜像 vs Dockerfile 大小差异解释：---
┌─────────────────────────────────────────────────────────┐
│ Dockerfile (1KB)                                        │
│ 只包含构建指令，不是镜像本身                            │
├─────────────────────────────────────────────────────────┤
│                                                         │
│ Docker 镜像 (133MB)                                     │
│ = 基础镜像层 + 新增层                                   │
│                                                         │
│ ├── python:3.12-slim 基础层 (~120MB)                    │
│ │      └── Python 3.12 + Debian 系统                    │
│ └── 新增层 (~13MB)                                      │
│       └── curl, ping, wget, unzip, zip                  │
│                                                         │
└─────────────────────────────────────────────────────────┘


| 文件        | 大小   | 内容             |
|-------------|--------|------------------|
| Dockerfile  | 1KB    | 构建指令         |
| 镜像        | 133MB  | 完整的可运行环境 |

基础镜像 python:3.12-slim 本身就 ~120MB，我们只加了约 13MB 的工具。这就像：
- 食谱（1KB）vs 做好的菜（133MB）

-------------2： 加载自定义镜像
导出/导入镜像
- 导出（在当前机器）：
docker save wlagent-sandbox:1.0 -o wlagent-sandbox-1.0.tar


- 导入（在其他机器）：
docker load -i wlagent-sandbox-1.0.tar


-- 压缩后导出更小：
docker save wlagent-sandbox:1.0 | gzip > wlagent-sandbox-1.0.tar.gz

-- 压缩导入时：
gunzip -c wlagent-sandbox-1.0.tar.gz | docker load
