## Memory 模块概述
Memory 模块是一个 分层记忆系统 ，包含以下核心概念：

|---------|------------------------|
| 概念    | 说明                   |
|---------|------------------------|
|会话记忆 | 原始对话记录，实时存储 |
|每日记忆 | 对话压缩后的摘要（按日期）|
|长期记忆 | 跨会话的重要信息汇总 |
|QA 对    | 从记忆中提取的问答对，用于检索 |
|向量索引 | 用于语义搜索的向量数据库 |
|BM25索引 | 用于关键词搜索的倒排索引 |

│   └── ...

│   ├── 2026-05-09.md                     # 压缩后的对话摘要
│   ├── 2026-05-10.md
│   └── ...

│   ├── 2026-05-10_qa.md
│   └── MEMORY_QA.md                     # 长期记忆QA对（从MEMORY.md提取）
│
├── MEMORY.md                        # 🗂️ 长期记忆文件（汇总）
│
├── MEMORY_QA.md                     # 🔍 长期记忆QA文件（索引的副产物）
│

    └── ...
    
    

    
==============================================================================
----------- 1. tool_result/ - 工具结果压缩目录
文件命名 ： {tool_call_id}.txt （工具调用ID）

内容 ：压缩后的工具原始输出结果

作用 ：

- 当工具输出超过阈值（如 4000 字符）时，压缩到 .txt 文件
- 原始消息中替换为文件引用路径
- 可通过 tool_call_id 加载原始内容


==============================================================================
-----------2. 索引构建流程（ build_index ）
┌─────────────────────────────────────────────────────────────┐
│                    build_index() 触发条件                     │
│         memory/ 或 MEMORY.md 文件发生变化时触发                │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  1. 增量检测：对比文件的 mtime（修改时间）                     │
│     - 新增文件 → 索引                                        │
│     - 已修改文件 → 删除旧索引，重新索引                        │
│     - 已删除文件 → 移除索引                                   │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  2. QA 提取流程                                              │
│                                                             │
│  memory/2026-05-09.md ──QA提取──▶ memory_qa/2026-05-09_qa.md│
│  MEMORY.md ──────────────────────▶ memory_qa/MEMORY_QA.md    │
│                                                             │
│  每个QA对独立成块，包含：                                     │
│  - Q: 问题                                                   │
│  - A: 回答                                                   │
│  - source: 来源文件                                           │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  3. 向量索引构建（基于QA文件）                                 │
│                                                             │
│  QA文本 → Embedding向量 → SQLite存储 + FAISS索引              │
│                                                             │
│  元数据记录：                                                 │
│  - source: 来源文件（如 "2026-05-09"）                        │
│  - type: "qa_chunk"                                          │
│  - qa_pair: {question, answer}                              │
│  - chunk_index: QA序号                                       │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  4. BM25索引构建（基于原文）                                   │
│                                                             │
│  直接对 .md 文件内容建立倒排索引                                │
└─────────────────────────────────────────────────────────────┘

==============================================================================
----------- 3. 搜索流程

用户查询 → 混合搜索（向量 + BM25）
              │
              ├── 向量搜索 ──▶ 找到 QA chunk
              │                 │
              │                 ▼
              │            根据 metadata.source
              │            定位原始文件
              │               │
              └── BM25搜索 ──▶ 找到原始文档
                               │
                               ▼
                        返回：chunk内容 + 源文件路径 + 源文件内容

=============================================================================
|--------|--------|------|
| 源文件 | QA文件 | 说明 | 
| memory/2026-05-09.md | memory_qa/2026-05-09_qa.md | 每日摘要 → 每日QA |
| MEMORY.md | memory_qa/MEMORY_QA.md | 长期记忆 → 长期QA |

=============================================================================

- memory/ 目录下的 md 文件是 按日期 存储的，不是按 session
- 一个 md 文件（如 2026-05-09.md ）汇总了当天 所有 session 的对话摘要 ----  代码是对当天所有的session进行汇总
- 不是与 dialog/ 中每个 jsonl 一一对应


当前文件对应关系 ：
dialog/
├── session_A_2026-05-09.jsonl  ─┐
├── session_B_2026-05-09.jsonl  ─┼─ 合并摘要 ──▶ memory/2026-05-09.md
└── session_C_2026-05-09.jsonl  ─┘
